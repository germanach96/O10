    Measure in each cell

    How it is measured

    Forecast = base × (1 + trend), trend capped at ±50%. Each row uses every case where its trend exists, and is compared with the same base without trend on those same cases.

    Sold, base and last year come from the latest snapshot that has the code (new perimeter after 2026.M02). The trend comes from what each snapshot showed. The Consensus of older snapshots is scaled to the new perimeter code by code.

    Seasonality: index of the House (Regular items, sell-in), mean of the last 2 years.

    Appearance

    Trend analysis

    Rows: every trend (sell-in, sell-out and 50/50 mixes, by EAN, product line, brand and house; cascade = the EAN's sell-out, else its line's, else its brand's, else its house's). Columns: the base the trend multiplies and the horizon, counted from the snapshot (3M = months 1–3, as WAPE90). Regular items only. Only snapshots whose months have all closed. Hover a cell for every figure.

    6-month trends

    Last 6 closed months against the same 6 a year earlier.

    12-month trends

    Last 12 closed months against the 12 before. Sell-out goes back to 2024.M07, so a 12-month sell-out trend only exists from 2025.M07 on.
