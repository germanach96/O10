House

    Measure in each cell

    How it is measured

    Common base = last 12 months’ volume ÷ 12 × the House seasonal index of each month. Trend capped at ±50%.

    Full: base × (1 + T). Half: base × (1 + T/2), since the 12-month mean already carries half a year of growth. Over time: each month grows from the centre of the mean (6.5 months back) to that month. Last year: same months LY × (1 + T).

    Each row uses every case where its trend exists; its four columns use the same cases.

    Sold, base and last year come from the latest snapshot that has the code (new perimeter after 2026.M02). The trend comes from what each snapshot showed. The Consensus of older snapshots is scaled to the new perimeter code by code.

    Seasonality: index of the House (Regular items, sell-in), mean of the last 2 years.

    Trend analysis

    Rows: every trend (sell-in, sell-out and 50/50 mixes, by EAN, product line, brand and house; cascade = the EAN's sell-out, else its line's, else its brand's, else its house's). Columns: how the trend is applied and the horizon, counted from the snapshot (3M = months 1–3, as WAPE90). The first three use the same base (last 12 months’ volume × the House seasonality), so they compare like with like; the fourth is the second comparison, entirely on last year. Regular items only. Only snapshots whose months have all closed. Hover a cell for every figure.
